# UI をレビューする
UIの操作を確かめるためのレビュー用スキル。変更された画面について、「操作」を中心に次の観点で確認してください。
- クリック・入力・送信が、確定/キャンセルのタイミングも含めて意図どおりに動くか
- 連打・二重送信など同じ操作を繰り返しても状態が壊れないか（連続クリック、送信中の多重実行など）
- 取り消せない操作（削除・アーカイブ等）は実行前に確認が入るか
- 操作要素にラベルが付き、キーボードだけで一通り操作できるか（components.md）
- 操作の結果が画面に正しく反映されるか（一覧への反映、空状態への遷移、無効化解除など）
- 空状態・エラー状態・ローディングが用意されているか
- 状態が表示用コンポーネントに漏れていないか
- 表示確認の手順を一言添える
